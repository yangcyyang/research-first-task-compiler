# 人工审阅与决策规则

## 1. 人审什么

人主要审阅：

- 目标；
- 边界；
- 核心模型；
- 关键取舍；
- 高风险例外；
- 最终可接受性。

人默认不审阅：

- 每一个字段；
- 每一条格式；
- 每一个低风险默认值；
- AI 可以自动完成的机械一致性检查；
- 与当前决策无关的完整证据。

## 2. 审阅优先级

将候选问题按以下因素排序：

```text
优先级 =
业务影响
× 不确定性
× 不可逆性
× 证据冲突
× 返工成本
```

不要求计算虚假的精确分数。可以使用高、中、低等级并说明依据。

## 3. 决策升级矩阵

| 影响 | 不确定性 | 处理 |
|---|---|---|
| 高 | 高 | 必须由人决定 |
| 高 | 低 | 人快速确认 |
| 低 | 高 | AI采用可逆默认方案并记录 |
| 低 | 低 | AI直接执行 |

## 4. 决策卡触发条件

生成决策卡，当：

- 两个方案会导致不同业务结果；
- 选择会改变状态、权限、统计口径或模块边界；
- 修改成本高；
- 资料相互冲突；
- 有合规、安全、财务或运营影响；
- 用户必须承担明显风险。

不要为颜色、排序、默认分页等低影响问题创建决策卡。

## 5. 决策卡叙事顺序

```text
一句话结论
→ AI建议
→ 决策问题
→ 方案A / 方案B
→ 推荐原因
→ 预期效果
→ 风险
→ 可逆性
→ 影响范围
→ 证据
→ 需要用户做什么
```

## 6. 用户反馈的结构化处理

支持：

```text
确认
局部修正：……
查看明细：……
退回：……
暂缓：……
```

用户只修正一项时：

- 不重做整张卡；
- 标记受影响字段；
- 更新下游影响；
- 保持未受影响内容不变；
- 在变更记录中说明。
