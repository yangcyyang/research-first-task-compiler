# 渐进式展示规则

## 1. 三层不是三次审批

三层的关系是：

- 第一层：审批层；
- 第二层：解释层；
- 第三层：证据层。

用户确认第一层后，默认直接进入下一阶段，不再强制审阅第二层和第三层。

## 2. 三个不同问题

设计输出时必须区分：

1. AI 是否已经生成这些信息？
2. 用户是否可以查看这些信息？
3. 用户是否必须审阅这些信息？

默认答案：

| 层级 | AI准备 | 用户可查看 | 用户必审 |
|---|---:|---:|---:|
| 第一层 | 是 | 是 | 是 |
| 第二层 | 是或按需补全 | 是 | 否 |
| 第三层 | 是并持续维护 | 是 | 否 |

## 3. 第一层的合格标准

第一层必须让用户在不阅读明细的情况下完成下列动作之一：

- 确认；
- 局部修正；
- 要求查看某一项明细；
- 退回。

如果第一层不能支持判断，它就不是合格的决策摘要。

## 4. 第一层信息顺序

统一采用：

```text
结论
→ 当前状态
→ 最重要内容
→ 变化或取舍
→ 风险
→ 待确认
→ AI建议动作
```

## 5. 明细下钻

用户提出“查看明细”时：

- 只显示被询问部分；
- 先给该部分一句话结论；
- 再展示必要明细；
- 最后给来源或证据入口；
- 不自动附上整个完整记录。

## 6. 重要信息提升规则

以下内容必须出现在第一层：

- 会改变目标或产物；
- 会改变范围或非目标；
- 会改变核心用户、核心对象或主流程；
- 会影响方案选择；
- 会造成高返工成本；
- 证据明显冲突；
- 对结果有效性有重大限制；
- 需要用户承担风险；
- 无法通过既定验收标准。

## 7. 不应出现在第一层的内容

除非它们直接影响决策，否则下沉：

- 全部资料目录；
- 完整字段表；
- 全部异常场景；
- 长篇方法论介绍；
- 逐项调研笔记；
- 低风险默认值；
- 机械性自检明细；
- 与当前决策无关的历史版本。

## 8. 审阅预算

建议第一层：

- 300～700 个中文字符；
- 3～5 个核心点；
- 1～3 个风险；
- 0～3 个确认点；
- 1 个明确推荐动作。

复杂程度高时可以略增，但不能把第一层变成全文摘要。
