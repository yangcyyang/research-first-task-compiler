# Acceptance Checklist

## Scope

- [ ] All in-scope items are addressed.
- [ ] No unapproved scope expansion occurred.
- [ ] Out-of-scope items remain excluded.

## Functional behavior

- [ ] Critical user flow works end to end.
- [ ] Error and empty states are handled.
- [ ] Data persists and restores where required.
- [ ] Existing behavior has not regressed.

## Engineering quality

- [ ] Required schema/deterministic checks pass.
- [ ] Build succeeds.
- [ ] Relevant tests pass.
- [ ] Lint/type checks pass where available.
- [ ] New dependencies are justified.
- [ ] Secrets and sensitive data are not committed.

## Reuse and compliance

- [ ] Reused code/components match approved source/version.
- [ ] License obligations are documented.
- [ ] Attribution/notices are included where required.
- [ ] Security and privacy assumptions are recorded.

## Evaluation and review

- [ ] Golden cases were run or marked untested.
- [ ] Facts, inference, and runtime evidence are separated.
- [ ] Independent review was performed when required.
- [ ] All red/yellow/gray items appear in the review package.
- [ ] Required human approvals are recorded.

## Delivery

- [ ] Setup and run instructions are current.
- [ ] Changed files/modules are listed.
- [ ] Known limitations are explicit.
- [ ] Untested items are explicit.
- [ ] Evidence supports each acceptance claim.
- [ ] Rollback or recovery notes exist where relevant.
