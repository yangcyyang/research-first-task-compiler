# Quick Natural-Language Commands

These are shortcuts, not mandatory syntax.

1. `我想做一个……先展示任务卡，等我确认后再调研。`
2. `确认任务卡 TC-1。`
3. `修改：……` 或 `补充：……`（旧确认失效，重出新版本任务卡）
4. `调研现有产品和开源项目，快速阅读入围项目，给我方案卡。`
5. `方案 A 具体讲讲。`（从详情文件展开，不现编）
6. `我选方案 A（RP-1）；生成计划模式交接包。`
7. `只把推荐结论、备选目录和需要我决定的内容给我。`
8. `当前结果的问题是……我希望改成……`
9. `按任务卡验收标准检查是否真的完成。`

Explicit skill invocation where supported:

`使用 research-first-task-compiler：<你的自然语言任务>`

Claude Code:

`/research-first-task-compiler <你的任务>`
